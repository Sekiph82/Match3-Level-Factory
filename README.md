# Match3 Level Factory prototype

This Unity 6000.6.5f1 project is the R06 M00–M03 prototype. It contains a
LevelDraft editor, a LevelSO import/export bridge for the Unity sample, and a
bounded Python 3 UltraGem reference pipeline. All generated drafts are marked
`PROTOTYPE_ONLY`; MATCH3_ENGINE is the sole authority for final rules and
validation.

The prototype adapter pins and calls the existing LibraStack SDK board-solver
and horizontal/vertical line-detector APIs for plain one-layer pieces. It
rejects semantics those APIs cannot currently represent. Results remain
reference-only while the Engine package and ENG-M24 acceptance are pending.

Open the project root in Unity and choose **Tools → Match3 Factory → Level Draft
Studio**. The window can paint a single-layer board, holes and glass, validate,
undo/redo, save/open LevelDraft JSON, and import/export supported sample
LevelSO assets. The sample adapter rejects semantics LevelSO cannot represent.

The Python environment is pinned to Python 3.12.10 in `Tools/UltraGem/.python-version`.
Install it with `python -m pip install -r Tools/UltraGem/requirements-lock.txt`,
then run the test suite with `python -m unittest discover -s Tools/UltraGem/tests -v`.
Run a small reference generation with:

```powershell
python Tools/UltraGem/factory_pipeline.py --rows 8 --columns 8 --colors 3 --seed 31 --candidates 1 --runs 2 --max-moves 20 --profile Coral_Rescue --output Artifacts/Prototype/example.json
```

Read one previous UltraGem donor run as **reference checkpoints** (not a
playback or a WIN). The input must have been generated by the existing pipeline
and the output path must be a new `.json` file in an existing project folder:

```powershell
python Tools/UltraGem/preview_reference_checkpoints.py --input Artifacts/Prototype/example.json --candidate 0 --policy smart --run 0 --output Artifacts/Prototype/checkpoint-preview-new.json
```

Existing files are never overwritten. The CLI can instead print JSON to
stdout when `--output` is omitted. In Unity open **Tools → Match3 Factory →
Level Draft Studio → UltraGem checkpoints** and select the created file. This
read-only inspector verifies the stored pre-move numeric checkpoint SHA256,
shows cumulative statistics, and rejects unsupported Engine/WIN claims. It
cannot show a real cascade grid, validate a goal, or certify playability.
For the separate original FX geometry preview use **Neutral FX rehearsal**.
Reduced-effects mode displays one static frame. Both inspectors stay in
Editor-only assemblies and must never appear in exported games.

The Unity EditMode tests use the installed Unity 6000.6.5f1 editor and can be
run with `-runTests -testPlatform editmode`. Source revisions, notices, and
file-level import hashes are recorded under `Tools/UltraGem/upstream` and
`ThirdParty/UnityGameSimulation`.

`ENG-M24` remains planned in MATCH3_ENGINE. The prototype does not claim Engine
compatibility, authoritative simulation parity, final difficulty, publishable
packs, or milestone acceptance. See the root `TASKS.md` for current blockers.
